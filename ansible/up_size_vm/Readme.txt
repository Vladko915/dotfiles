# Збільшення розміру диска VirtualBox VM (Ubuntu + LVM)

Інструкція перевірена на прикладі збільшення `kube-control` з 10GB до 20GB.
Той самий процес підходить для будь-якої іншої ВМ (наприклад `kube-worker1`, `kube-worker2`) — просто підставте свою назву ВМ і потрібний розмір.

## Частина 1 — Ззовні (на хост-машині, через VBoxManage)

### 1. Перевірити наявність снапшотів

```bash
VBoxManage snapshot <ІМ'Я_ВМ> list
```

Якщо снапшоти є — VirtualBox **не дозволить** ресайзнути диск, поки вони не видалені.

### 2. Вимкнути ВМ

```bash
VBoxManage controlvm <ІМ'Я_ВМ> poweroff
```

### 3. Видалити снапшоти (якщо є)

Видаляти по черзі, за потреби кілька разів (спочатку найновіший):

```bash
VBoxManage snapshot <ІМ'Я_ВМ> delete <UUID>
```

Зачекати завершення (може тривати кілька хвилин — VirtualBox зливає дельта-файли в базовий диск). Перевірити, що список порожній:

```bash
VBoxManage snapshot <ІМ'Я_ВМ> list
```

### 4. Знайти актуальний шлях до диска

```bash
VBoxManage showvminfo <ІМ'Я_ВМ> | grep -i vdi
```

Переконатись, що шлях більше **не** містить `/Snapshots/` — тобто вказує напряму на основний файл диска.

### 5. Збільшити диск

```bash
VBoxManage modifymedium "<шлях_до_диска.vdi>" --resize <новий_розмір_в_MB>
```

Приклади розмірів у MB:
- 15 GB → `15360`
- 20 GB → `20480`
- 30 GB → `30720`
- 40 GB → `40960`

### 6. Перевірити новий розмір

```bash
VBoxManage showhdinfo "<шлях_до_диска.vdi>"
```

Має показати `Capacity: <новий_розмір> MBytes`.

### 7. Запустити ВМ

```bash
VBoxManage startvm <ІМ'Я_ВМ> --type headless
```

## Частина 2 — Всередині гостьової ОС (по SSH)

### 1. Перевірити нову структуру дисків

```bash
lsblk
```

Диск (`sda`) вже покаже новий повний розмір, але розділ з LVM (зазвичай `sda3`) — ще старого розміру.

### 2. Встановити утиліту для розширення розділів (якщо ще немає)

```bash
sudo apt update
sudo apt install -y cloud-guest-utils
```

### 3. Розширити розділ

Підставте правильний номер розділу з `lsblk` (типово `sda3`, де саме розташований LVM PV):

```bash
sudo growpart /dev/sda 3
```

Перевірити результат:

```bash
lsblk
```

### 4. Розширити LVM Physical Volume

```bash
sudo pvresize /dev/sda3
```

### 5. Розширити Logical Volume на весь вільний простір

```bash
sudo lvextend -l +100%FREE /dev/mapper/ubuntu--vg-ubuntu--lv
```

### 6. Розширити файлову систему

Для `ext4` (стандартно на Ubuntu):

```bash
sudo resize2fs /dev/mapper/ubuntu--vg-ubuntu--lv
```

Якщо файлова система `xfs` — замість цього:

```bash
sudo xfs_growfs /
```

### 7. Перевірити результат

```bash
df -h /
```

Має показати новий, збільшений розмір диска.

---

## Примітки

- Назви LVM Volume Group / Logical Volume (`ubuntu-vg-ubuntu-lv`) можуть відрізнятись між ВМ — перевіряйте точну назву через `lsblk` чи `sudo lvs` перед виконанням команд.
- Номер розділу (`sda3`) теж може відрізнятись — орієнтуйтесь на `lsblk`, шукайте розділ, який змонтований як LVM PV.
- Якщо диск має формат `.vmdk` замість `.vdi` — VirtualBox не вміє ресайзити VMDK напряму. Потрібно спершу сконвертувати в `.vdi`, зробити resize, і за потреби конвертувати назад.
