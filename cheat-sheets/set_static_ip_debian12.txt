show connections:

bash> nmcli connection show
NAME                UUID                                  TYPE  DEVICE
Wired connection 1  1********-*********-***********   ethernet  enp2s0
lo                  2********-*********-***********   loopback  lo
TP-Link_000A        3********-*********-***********   wifi      wlp3s0


"TP-Link_000A" - pseudo router-name,
change to real.

For enp2s0 (192.168.0.5)
bash>
sudo nmcli con mod "Wired connection 1" ipv4.addresses 192.168.0.5/24
sudo nmcli con mod "Wired connection 1" ipv4.gateway 192.168.0.1
sudo nmcli con mod "Wired connection 1" ipv4.dns "8.8.8.8 8.8.4.4"
sudo nmcli con mod "Wired connection 1" ipv4.method manual
sudo nmcli con up "Wired connection 1"

For wlp3s0 (192.168.0.6)
bash>
sudo nmcli con mod "TP-Link_000A" ipv4.addresses 192.168.0.6/24
sudo nmcli con mod "TP-Link_000A" ipv4.gateway 192.168.0.1
sudo nmcli con mod "TP-Link_000A" ipv4.dns "8.8.8.8 8.8.4.4"
sudo nmcli con mod "TP-Link_000A" ipv4.method manual
sudo nmcli con up "TP-Link_000A"
